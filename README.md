\# Transport Vehicle Loader Animation



A transport-dashboard loading animation created with HTML, CSS, and JavaScript.



\## Features



\- Vehicle/cab animation

\- Animated route and moving GPS location pin

\- Rotating vehicle wheels

\- Loading percentage counter

\- Responsive dashboard UI

\- Accessible reduced-motion support

\- Click-to-preview dashboard navigation animation



\## Technologies



\- HTML5

\- CSS3

\- Vanilla JavaScript



\## Run locally



Open `index.html` in a browser.
